# Структура проекта после рефакторинга

Проект по-прежнему запускается так же:

```bash
python app.py
```

## Основные файлы

- `app.py` — создание Flask-приложения, подключение БД, LoginManager, CORS и регистрация маршрутов.
- `extensions.py` — общие расширения Flask: `db`, `login_manager`.
- `models.py` — все модели SQLAlchemy: товары, пользователи, корзина, заказы, журналы.
- `helpers.py` — общие вспомогательные функции: проверка роли администратора, аудит действий, история изменений, CSV-ответы, анализ проблем каталога.

## Папка `routes/`

- `routes/main.py` — главная HTML-страница.
- `routes/auth.py` — регистрация, вход, выход, проверка авторизации.
- `routes/products.py` — каталог, CRUD товаров, история изменений, восстановление из архива.
- `routes/sync.py` — синхронизация с Ozon и журнал синхронизаций.
- `routes/cart.py` — корзина пользователя.
- `routes/orders.py` — создание, просмотр, отмена и обработка заказов.
- `routes/analytics.py` — аналитика, контроль каталога, экспорт CSV и общий журнал действий.

## Frontend

- `templates/index.html` — основная HTML-страница.
- `static/script.js` — базовая логика каталога, авторизации, модалок и синхронизации.
- `static/shop.js` — логика магазина: корзина, заказы, аналитика, контроль каталога.
- `static/style.css` — весь дизайн интерфейса.
